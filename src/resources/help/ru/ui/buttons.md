## Кнопки

Панель инструментов находится сверху и содержит кнопки действий активной вкладки.

:::figure{side=block height=107}
![Панель инструментов сессии]({{img:ui.buttons.toolbar}})
Панель инструментов над холстом.
:::

### Панель инструментов {#toolbar}

Каждая вкладка сама решает, какие кнопки показывает её панель.

### Режимы интерфейса {#ui-modes}

Плотность раскладки зависит от режима интерфейса — подробности в справке активной вкладки: [Сравнение](help://comparison#toolbar), [Лупа](help://magnifier#toolbar), [Раскладки](help://mc_layouts#toolbar). Смена режима — в разделе [Настройки → Оформление](help://settings#interface).

### Несколько действий на одной кнопке {#multi-action}

В зависимости от режима интерфейса одна кнопка может отвечать на несколько жестов:

- **Короткий клик** — основное действие или переключение.
- **Колесо** — подстроить значение без открытия диалога.
- **Удержание** — усиленный вариант у части кнопок.
- **Другие кнопки мыши** — дополнительные варианты в самом плотном режиме.

:::figure{side=block height=44}
![Удержание на кнопке списка]({{img:ui.buttons.long_press}})
Кнопка списка — короткий клик и удержание.
:::

### Найти действие по имени {#find-action}

Нажмите `Ctrl+Shift+P` ({{tr:menu.find_action}}), введите часть названия, затем запустите действие или откройте {{tr:action.palette.learn_more}} / `Ctrl+Enter`, если у строки есть тема справки.
