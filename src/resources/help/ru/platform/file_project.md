## Файлы и проекты

Загрузка изображений в сессию и портативные файлы проектов.

### Загрузка изображений {#loading-images}

- **Добавить файлы** — один или несколько файлов через {{tr:menu.find_action}} или кнопки самой вкладки.
- **Перетаскивание** — бросок в окно попадает в активную сессию — куда именно, см. справку вкладки: [Сравнение](help://comparison), [Лупа](help://magnifier).
- **Вставка** (`Ctrl+V`) — изображение из буфера; куда попадёт, см. справку вкладки.

![Оверлей направления вставки]({{img:platform.file_project.paste_overlay}})
`Ctrl+V` — оверлей направления вставки.

### Списки {#lists}

Списки принадлежат своей сессии — [Списки и всплывающие панели](help://ui.lists_flyouts). У каждой сессии своя вкладка — [Вкладки](help://tabs).

### Проекты {#projects}

- **Открыть** — `Ctrl+Shift+O` или {{tr:menu.find_action}} открывает файл `.imgsli`. При открытии активная вкладка получает имя файла.
- **Сохранить** — `Shift+S` пишет в текущий файл; если ещё не сохраняли, вместо этого открывается **Сохранить как**.
- **Сохранить как** — `Ctrl+Shift+S`. Предлагает имя переименованной вкладки, иначе {{tr:menu.project_untitled}}.
- **Портативный пакет** — один файл хранит раскладку сессий, настройки сессий и встроенные копии изображений.
- **Отсутствующие исходники при сохранении** — если путь из списка больше не существует, проект всё равно сохраняется; это изображение пропускается, а предупреждение перечисляет его.
- **Настройки приложения** — тема, язык и горячие клавиши остаются в настройках приложения и не входят в файл проекта.

### Ассоциация файлов в Windows {#windows-file-association}

В Windows двойной клик по файлу `.imgsli` открывает его в приложении. Если система спрашивает, каким приложением открыть, выберите Improve ImgSLI один раз.
