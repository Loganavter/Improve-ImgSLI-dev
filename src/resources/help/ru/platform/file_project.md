## Файлы и проекты

Загружайте изображения в списки сессии, вставляйте из буфера и открывайте или сохраняйте портативные проектные файлы, которые хранят раскладку сессий, настройки сравнения и копии исходных изображений.

### Загрузка изображений {#loading-images}

- **Добавить файлы** — кнопки добавления у стороны (или {{tr:menu.find_action}}) выбирают один или несколько файлов.
- **Перетаскивание** — бросок в окно кладёт файлы в список на стороне под курсором.
- **Вставка** (`Ctrl+V`) — из буфера; появляется оверлей направления: клик по стрелке выбирает сторону, `Esc` отменяет.

### Списки {#lists}

Списки принадлежат своей сессии — [Списки и всплывающие панели](help://ui.lists_flyouts). У каждой сессии своя вкладка — [Вкладки](help://tabs).

### Проекты {#projects}

- **Открыть** — `Ctrl+Shift+O` или {{tr:menu.find_action}} открывает файл `.imgsli` из меню File. При открытии проекта активная вкладка получает имя файла. Проект восстанавливает сессии, настройки сравнения и встроенные копии изображений.
- **Сохранить** — `Shift+S` пишет в текущий файл; если ещё не сохраняли, вместо этого открывается **Сохранить как**. Сохранение также меняет имя файла, если вкладку переименовали.
- **Сохранить как** — `Ctrl+Shift+S`. Предлагает имя переименованной вкладки, если активная вкладка своя, иначе {{tr:menu.project_untitled}}.
- **Портативный пакет** — один файл хранит раскладку сессий, настройки сравнения и встроенные копии изображений.
- **Отсутствующие исходники при сохранении** — если путь из списка больше не существует, проект всё равно сохраняется; это изображение пропускается, а предупреждение перечисляет его.
- **Настройки приложения** — тема, язык и горячие клавиши остаются в настройках приложения и не входят в файл проекта.

### Ассоциация файлов в Windows {#windows-file-association}

В Windows установщик связывает `.imgsli` с Improve ImgSLI: двойной клик открывает проект, а файл показывает иконку документа приложения. Сборки EXE также регистрируют ассоциацию при старте.

Если в свойствах всё ещё «Выбор приложения», выберите Improve ImgSLI один раз или запустите приложение с `--register-file-types`, чтобы зарегистрировать ассоциацию снова.
