## Hotkeys

Default key combinations below — most can be reassigned under {{tr:menu.settings}} → {{tr:settings.keyboard}}. Canvas `WASD`, arrow, `Space` movement and `+`/`-` zoom stay fixed.

### Discover first {#discover}

`Ctrl+Shift+P` plus a typed name beats memorizing a list — [find any action by name](help://ui.buttons#find-action). `F1` highlights the action in the palette.

### Platform {#platform}

- `Ctrl+,` — Settings
- `Ctrl+F1` — Help
- `Ctrl+N` — Session picker / new session
- `Ctrl+Tab` / `Ctrl+Shift+Tab` — Next / previous workspace session
- `Ctrl+Shift+P` — {{tr:menu.find_action}}
- `Ctrl+V` — Paste image
- `Ctrl+Shift+O` / `Shift+S` / `Ctrl+Shift+S` — Open / save / save project as (`.imgsli`) — [Files and Projects](help://file_management#projects)
- `Ctrl+Q` — Quit

Reassign under [Settings → Keyboard](help://settings#keyboard).

### Tab shortcuts {#tab-shortcuts}

Each tab lists its own shortcuts in its help: [Comparison](help://comparison), [Multi Compare](help://multi_compare), [Triage and Review](help://gallery_triage), [Video Editor](help://video).

### Keyboard navigation {#keyboard-navigation}

- `F1` — contextual help for the focused element — see [Buttons and Controls](help://ui.buttons#find-action).
- In {{tr:menu.find_action}} (`Ctrl+Shift+P`): `↑` / `↓` move the selection, `Enter` runs it, `Ctrl+Enter` opens {{tr:action.palette.learn_more}}, `Esc` closes the palette.
- Focus follows the pointer on the canvas: the keyboard drives actions through the palette.
