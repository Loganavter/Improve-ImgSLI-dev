## Tabs

The tab strip above the workspace holds one tab per open session. The active tab decides what the canvas, toolbar, and lists show.

### Tab strip {#tab-strip}

- **Switching** — a click on a tab activates its session.
- **Closing** — the close button removes the tab's session. Closing the last session replaces it with the session picker, so the strip never stands empty.
- **Context menu** — rename, duplicate, close the other tabs, or create a new tab; the set depends on the tab.
- **Titles** — untouched tabs show the session-type name in the current language; a rename stores a custom title that survives language switches.
