## Gallery Overview

The {{tr:image_gallery.tab_name}} shows one folder as cards grouped into near-duplicate series.

### Folder opening {#open-folder}

- **{{tr:image_gallery.pick_folder}}** — the folder picker; empty tabs show {{tr:image_gallery.empty_state}}.
- **File drop** — dragged files land the same way as through the button; a single file opens alone, the parent folder is not scanned.
- **{{tr:action.workspace.new_image_gallery}}** — new gallery sessions from {{tr:menu.find_action}} (`Ctrl+Shift+P`).

### Series {#series}

Loaded folders group near-duplicates into series.

- **Series** — two or more near-duplicates form a series; an image with no near-duplicate stays without a series.
- **Regrouping** — a reopened folder groups again.
- **Pinned cards** — a card dragged into another series stays there; Reset returns automatic grouping.

### Toolbar {#toolbar}

The fixed row at the top reads left to right: the open-folder button, then the filter field, then Sort, then the Algorithms|AI switch; the grid/list view sits at the right edge. Sort by AI quality is offered only in the AI domain.

### Grid sort and filter {#grid-sort-filter}

- **{{tr:image_gallery.view}}** — {{tr:image_gallery.view_grid}} or {{tr:image_gallery.view_list}}.
- **{{tr:image_gallery.sort_by}}** — {{tr:image_gallery.sort_rank}}, {{tr:image_gallery.sort_name}}, {{tr:image_gallery.sort_date}}, or {{tr:image_gallery.sort_quality}}.
- **Filter** — {{tr:image_gallery.filter_placeholder}} narrows the grid.

### Stats and compare {#stats-and-compare}

Image, series, and duplicate counts for the folder.

- **Compare** — the best image of each series plus the images without a series go to Image Compare.
- **Card click** — Quick Look with the image's quality readings.
