## Ask AI

Ask about a single image, a selection, or a whole series.

### Ask about a selection {#ask-selection}

- **{{tr:image_gallery.ask_ai.action}}** — opens {{tr:image_gallery.ask_ai.title}} for that card or the current selection.
- **Ready prompt** — start from the ready prompt: {{tr:image_gallery.ask_ai.default_prompt}}.
- **Badge** — {{tr:image_gallery.ask_ai.read_badge}} marks AI-supplied text.

### Ask about a series {#ask-series}

The series-header menu asks about every member at once. See [Quality Metrics](help://gallery_quality).

### Set up AI {#setup}

- **AI setup** — set up AI in [Settings](help://settings).
- **Watch progress and read errors** — {{tr:image_gallery.ask_ai.busy}}; failures report {{tr:image_gallery.ask_ai.error}}.
- **Advisory only** — answers change nothing.
