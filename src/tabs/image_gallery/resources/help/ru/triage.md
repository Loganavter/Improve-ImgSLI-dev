## Триаж и разбор

По одному победителю в каждой серии, отклонённые — вне папки.

### По одному лучшему в серии {#keep-best}

- **{{tr:image_gallery.action.keep_best}}** — лучшее в каждой серии отмечено, остальное отклонено.
- **{{tr:image_gallery.action.keep_best_desc}}** — лучшее в каждой серии отмечено.
- **Показать все** — все флаги отклонения сняты.

### Метки лучшего и отклонения {#make-best-reject}

- **{{tr:image_gallery.card.make_best}}** — это изображение назначено победителем своей серии.
- **{{tr:image_gallery.card.reject}}** — флаг отклонения у одного изображения переключён.
- **Удаление из сетки** — `Space` / `Delete` убирают выделенные карточки из сетки.

### Удаление отклонённых {#clean-review}

- **{{tr:image_gallery.action.clean_rejected}}** — {{tr:image_gallery.action.clean_rejected_desc}} (`_rejected/`). Перемещение сначала показывается в предпросмотре; файлы остаются на диске.
- **Отмена перемещения** — кнопка Undo в уведомлении возвращает перемещённые файлы в папку.

### Повторная проверка папки {#run-triage}

{{tr:image_gallery.action.run_triage}} заново открывает текущую папку и проверяет её заново.

### Образец для сравнения {#set-as-source}

{{tr:image_gallery.action.set_as_source}} и {{tr:image_gallery.card.set_as_source}} выбирают образец, с которым сравнивать. См. [Метрики качества](help://gallery_quality#reference-source).
