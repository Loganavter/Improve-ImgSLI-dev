## Обзор галереи

{{tr:image_gallery.tab_name}} показывает одну папку карточками, сгруппированными в серии почти одинаковых изображений.

### Открытие папки {#open-folder}

- **{{tr:image_gallery.pick_folder}}** — выбор папки; пустая вкладка показывает {{tr:image_gallery.empty_state}}.
- **Перетаскивание файлов** — перетащенные файлы добавляются так же, как через кнопку; одиночный файл открывается сам, родительская папка не сканируется.
- **{{tr:action.workspace.new_image_gallery}}** — новые сессии галереи из {{tr:menu.find_action}} (`Ctrl+Shift+P`).

### Серии {#series}

Загруженная папка группирует почти одинаковые изображения в серии.

- **Серия** — два и более почти одинаковых изображения образуют серию; изображение без похожих остаётся без серии.
- **Перегруппировка** — заново открытая папка группируется снова.
- **Закреплённые карточки** — карточка, перетащенная в другую серию, остаётся там; сброс возвращает автоматическую группировку.

### Панель инструментов {#toolbar}

Фиксированная строка сверху читается слева направо: кнопка открытия папки, затем поле фильтра, затем сортировка, затем переключатель Algorithms|AI; вид сетка/список — у правого края. Сортировка по качеству ИИ предлагается только в AI-домене.

### Сортировка и фильтр сетки {#grid-sort-filter}

- **{{tr:image_gallery.view}}** — {{tr:image_gallery.view_grid}} или {{tr:image_gallery.view_list}}.
- **{{tr:image_gallery.sort_by}}** — {{tr:image_gallery.sort_rank}}, {{tr:image_gallery.sort_name}}, {{tr:image_gallery.sort_date}} или {{tr:image_gallery.sort_quality}}.
- **Фильтр** — {{tr:image_gallery.filter_placeholder}} сужает сетку.

### Статистика и сравнение {#stats-and-compare}

Число изображений, серий и повторов в папке.

- **Сравнение** — лучшее изображение каждой серии плюс изображения без серии уходят в сравнение изображений.
- **Клик по карточке** — быстрый просмотр с замерами качества изображения.
