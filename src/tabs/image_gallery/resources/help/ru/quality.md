## Метрики качества

Каждое изображение получает оценку от 0 до 100; выше — лучше. Оценка сводит несколько замеров изображения, таких как резкость, экспозиция, шум и цвет.

### Замерьте оценку {#measured-metrics}

Оценка считается автоматически; подробности — в быстром просмотре.

### Посмотрите, где видны оценки {#where-scores}

- **Быстрый просмотр** — строки метрик каждого изображения с сырыми показаниями.
- **Точки на карточках** — точки на карточке показывают замечания.
- **{{tr:image_gallery.sort_quality}}** — сначала сортирует по качеству ИИ; изображения без оценки уходят в конец.

### Сравните с образцом {#modes}

Сравните с образцом: назначьте его сами.

### Назначьте образец {#reference-source}

**Источник** — изображение, выбранное образцом для сравнения.

{{tr:image_gallery.action.set_as_source}} назначает образец для сравнения. Оценки обновятся после назначения.
