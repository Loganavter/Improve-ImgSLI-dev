## Выбор сессии и вкладки

Откройте проект или начните новый.

:::figure{side=block width=420}
![Выбор сессии]({{img:platform.workspace.session_picker}})
{{tr:action.workspace.open_session_picker}}.
:::

### Откройте сессию {#session-picker}

- Главный экран показывает все подключённые типы вкладок. Клик по любой карточке открывает страницу.
- Недавние — откройте недавний проект ниже.
- Перетащите файл проекта в список, чтобы добавить его в программу.

### Откройте без выбора {#new-session-actions}

Откройте через {{tr:menu.find_action}} (`Ctrl+Shift+P`).

{{tr:action.workspace.open_session_picker}} возвращает на стартовую страницу.
