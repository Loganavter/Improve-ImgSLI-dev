### Открытие сессии {#session-picker}

- Главный экран показывает все подключённые типы вкладок. Клик по любой карточке открывает страницу.
- Недавние проекты ниже — для повторного открытия.
- Файл проекта, перетащенный в список, попадает в программу.

### Открытие без выбора {#new-session-actions}

Открытие через {{tr:menu.find_action}} (`Ctrl+Shift+P`).

{{tr:action.workspace.open_session_picker}} возвращает на стартовую страницу.
