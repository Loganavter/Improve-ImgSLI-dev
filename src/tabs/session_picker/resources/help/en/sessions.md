## Session Picker

The home page of a new tab: it lists the session types you can start and your recent projects.

![Session Picker]({{img:platform.workspace.session_picker}})

:::

### Session Picker {#session-picker}

- The home screen lists every connected tab type, for example {{tr:workspace.session_types.image_compare}}, {{tr:image_gallery.tab_name}}. Click any card to open that page.
- Recent — the recent-projects shelf below. Click a card to open the project, right-click for its action menu. Projects can also be sorted and switched between grid and list views.
- Drag any project file (``.imgsli``) onto the shelf to add it to the app.

### Open a session without the picker {#new-session-actions}

From {{tr:menu.find_action}} (`Ctrl+Shift+P`):

- {{tr:action.workspace.new_image_compare}}
- {{tr:action.workspace.new_multi_compare}}

{{tr:action.workspace.open_session_picker}} returns to the home page.
