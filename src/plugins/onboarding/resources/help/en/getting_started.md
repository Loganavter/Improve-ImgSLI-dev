## Getting Started

Orientation for a fresh install. First launch shows a full-window overlay: pick a UI mode, then start working. The palette ({{tr:menu.find_action}}, `Ctrl+Shift+P`) runs any action.

### Pick a UI mode {#ui-mode}

- The overlay previews each mode — {{tr:settings.ui_mode_beginner}}, {{tr:settings.ui_mode_advanced}}, {{tr:settings.ui_mode_expert}} — with sample controls; mode buttons and dots switch between the slides.
- **{{tr:onboarding.start_button}}** confirms the highlighted mode and opens the workspace.
- The choice is not final: switch modes any time under [Settings](help://settings) → {{tr:settings.appearance}}.

### {{tr:workspace.session_types.image_compare}} workflow {#basic-workflow}

The session pairs two image lists. The [Comparison](help://comparison) view divides them at a split line, with the [Magnifier](help://magnifier) as the lens alternative. Sessions open from the [Session Picker](help://session_picker) or the palette ({{tr:action.workspace.new_image_compare}}). Results leave through [Export](help://export) (`Ctrl+S`) or the [Video Editor](help://video).

### {{tr:workspace.session_types.multi_compare}} path {#multi-compare}

A grid of slots for more than two images, opened from the [Session Picker](help://session_picker). Images fill slots and the grid saves through export. Details: [{{tr:workspace.session_types.multi_compare}}](help://multi_compare).

### Discover features {#discover}

`Ctrl+Shift+P` searches and runs any action; {{tr:action.palette.learn_more}} opens the matching help topic. `F1` opens the palette filtered to the focused chrome. Inside the Help window, the search field above the topic list jumps to matching pages. Next topics: [Workspace Tabs](help://session_picker), [Files and Projects](help://file_management), [Comparison](help://comparison), [Export](help://export), [Settings](help://settings).
